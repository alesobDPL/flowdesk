## Convención

Guardar cada plan como `YYYY-MM-DD-<tema>.md` en esta carpeta, siguiendo [writing-plans](../../../.agents/skills/writing-plans/SKILL.md).

Usar la cabecera y estructura de la skill instalada: objetivo, arquitectura y tecnologías confirmadas, enlace relativo al diseño aprobado, restricciones globales, aspectos de revisión y tareas verificables. Cada tarea debe especificar archivos, interfaces cuando correspondan, pasos con casillas y verificaciones concretas.

Revisar la cobertura del diseño y la coherencia de las tareas. No inventar tecnologías, comandos ni requisitos para completar un plan. Si falta una decisión necesaria para ejecutarlo, marcarla **Pendiente** y resolverla antes de considerar el plan listo.

Presentar el plan para revisión y acordar su ejecución conforme a la skill. Mantener el estado de las tareas y enlazar el plan desde el [roadmap](../../roadmap/README.md) cuando corresponda.
